## Learning Path

A practical progression for this collection:

1. **Start with manual enumeration**  
   Build foundational Linux discovery skills with `Breakout Basics: Manual Linux Enum`.

2. **Study files and backups**  
   Continue with the archive, backup, shadow-ledger, and sensitive-file labs.

3. **Explore TAR breakout concepts**  
   Work through TAR Trap Breakout, Archive Breakout, TAR Pit Breakout, and related challenges.

4. **Learn Linux capabilities**  
   Move to Capitally Restricted and TAR Capabilities Unleashed to understand capability-based privilege boundaries.

5. **Study GTFOBins**  
   Complete GTFOBins Bootcamp and learn how documented binary behavior can matter during authorized security assessments.

6. **Combine the concepts**  
   Finish with Cap the TAR, Crack the Root to connect TAR, capabilities, and root-access concepts.

## How to Use the Labs

- Use these labs only in environments where you have explicit authorization.
- Read each challenge carefully before beginning.
- Practice manual Linux enumeration before relying on automated tools.
- Record commands, observations, files, permissions, and configuration findings.
- Treat sensitive files and credentials as security-learning material, not as real-world targets.
- Use the labs to understand why a vulnerability or misconfiguration matters and how it can be mitigated.
- Keep notes on the defensive lesson behind every breakout technique.
